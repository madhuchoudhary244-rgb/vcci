# VCCI Website

Phase 1 provides the stable foundation for the Vision Computer & Coaching Institute website.

## Requirements

- Node.js 20.9.0 or later (an LTS release is preferred)
- npm 10 or later

## Commands

```bash
npm run dev
npm run lint
npm run build
npm run start
```

Open `http://localhost:3000` after starting the development server.

## Scope

This phase includes only the Next.js foundation, responsive design tokens, a placeholder home page, asset folders, environment-variable placeholders, and architecture documentation. Firebase, authentication, forms, results, and the actual public/admin features are intentionally deferred.

See [the project architecture](docs/PROJECT_ARCHITECTURE.md) before extending the application.
